# RateToFive

**RateToFive** is an ongoing project where users can rate teachers or professors based on the following criteria:

- **Knowledge and Delivery**
- **Interest and Stimulation**
- **Management and Organization**
- **Student-Professor Relations**

Users can also attach comments to their ratings. The platform will support ratings for teachers across different schools, allowing students to share valuable feedback about their educators.

> **Note:** The backend is currently under development. This repository is focused on the frontend, which is being built with React.js and Tailwind CSS. Placeholder data is being used for the time being.

## Features
- Rate teachers on multiple categories.
- Attach comments to each rating.
- Support for multiple schools (currently using placeholder data).
- Ongoing development of the backend and authentication features.

## Technologies Used
- **Frontend:** React.js, Tailwind CSS
- **Authentication (future):** JWT (JSON Web Token) for secure logins
- **Version Control:** Git/GitHub
